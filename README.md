# ServingHearts 🩸
**A PHP-based blood inventory and request management system built to streamline blood donation logistics.**

[![PHP Version](https://img.shields.io/badge/PHP-7.4%2B-777bb4.svg?style=flat-square&logo=php)](https://www.php.net/)
[![MySQL](https://img.shields.io/badge/MySQL-Database-4479A1?style=flat-square&logo=mysql)](https://www.mysql.com/)
[![Python](https://img.shields.io/badge/Python-Forecasting-3776AB?style=flat-square&logo=python)](https://www.python.org/)
[![XAMPP](https://img.shields.io/badge/XAMPP-Environment-FB8C00?style=flat-square&logo=xampp)](https://www.apachefriends.org/)

---

## 🚀 Features
* **Blood Inventory Management:** Real-time tracking of blood units and supplies.
* **Dual-Module System:** Comprehensive interfaces for both Administrators and Staff.
* **Request Processing:** Streamlined workflow for managing blood requests.
* **Predictive Analytics:** Forecasting scripts using Python to anticipate supply needs.

## 🛠️ Tech Stack
* **Backend:** PHP, MySQL
* **Frontend:** JavaScript, CSS, HTML
* **Data Science:** Python (Forecasting)

## ⚙️ Local Setup
1.  **Clone the repository**
    ```bash
    git clone [https://github.com/your-username/ServingHearts.git](https://github.com/your-username/ServingHearts.git)
    ```
2.  **Move to XAMPP**
    Copy the project folder to `xampp/htdocs/`.
3.  **Database Configuration**
    * Import the provided `.sql` file into your MySQL database.
    * Configure `config.php` or `db.php` with your database credentials.
4.  **Run Application**
    Start Apache and MySQL in XAMPP and visit `http://localhost/ServingHearts`.
