# ServingHearts

A PHP-based blood inventory and request management system.

## Features
- Blood inventory management
- User and admin modules
- Blood request processing
- Forecasting scripts in Python

## Tech Stack
- PHP
- MySQL
- JavaScript
- Python

## Local Setup
1. Clone the repository
2. Move it to `xampp/htdocs`
3. Import the database
4. Configure `config.php` / `db.php`
5. Start Apache and MySQL in XAMPP
